#  Excel Data Analysis Practice


This project contains multiple Excel datasets used for practicing **data cleaning, transformation, analysis, and reporting techniques** 
in Excel.

Each Excel file starts with a **raw dataset** and demonstrates various operations performed to convert the data into meaningful 
and usable insights.


The repository includes multiple Excel workbooks covering:

* Raw data handling
* Data cleaning techniques
* Data transformation
* Pivot Tables
* Charts & visualizations
* Basic analytics
* Dashboard-style summaries
* Excel formulas and functions

## 📊 Datasets Used

| File | Dataset | Description |
|------|---------|--------------|
| Data_Analysis_01 | Gym Equipment Sales | Monthly profit by category, supplier, and brand (2018 onward) — practice/synthetic dataset |
| Data_Analysis_02 | Car Specifications | Make, model, price, body style, horsepower, fuel economy — practice/synthetic dataset |
| Data_Analysis_03 | Client Revenue & Profit | Revenue, profit, and payment method by client and department — practice/synthetic dataset |
| Data_Analysis_04 | Employee Records (Dirty Data) | Employee ID, department, salary, start date — practice/synthetic dataset for cleaning |
| Data_Analysis_05 | Financial Sample | Segment/Country/Product sales with COGS, discounts, profit. Sourced from Microsoft's official [Financial Sample](https://go.microsoft.com/fwlink/?LinkID=521962) dataset, used in the [Simon Sez IT "Data Cleaning in Excel" webinar](https://www.youtube.com/watch?v=8Ix_VVcihqg). Includes "Raw Data" (messy) and "Sheet1" (cleaned) sheets, plus a "Text File" sheet from the same video's text-import exercise |
| Data_Analysis_06 | US Presidents & Party Data | President, party, VP, prior role, salary — intentionally messy for cleaning practice (exact original source unverified) |
| Data_Analysis_07 | Customer Purchases | Age, gender, marital status, purchase date/amount, location — practice/synthetic dataset |
| Data_Analysis_08 | 500 Greatest Albums | Year, Album, Artist, Genre, Subgenre, Sales (1955–2011). Based on [Rolling Stone's 500 Greatest Albums of All Time](https://www.kaggle.com/datasets/notgibs/500-greatest-albums-of-all-time-rolling-stone), adapted with a Total Sales column for teaching purposes |
| Data_Analysis_09 | Sales Data (Reconstructed Practice File) | Month, Store, Town, Store Code, Country, Manager, Category, Sales, Date — a reconstructed practice dataset modeled on the messy "sales data original" file used in the Simon Sez IT tutorial, since the original was no longer available |
| Data_Analysis_10 | Stock Price Data (OHLCV) | Date, Ticker, Name, Open, High, Low, Close, Volume — dirtied stock market data (duplicates, inconsistent whitespace) for cleaning practice; exact original source unverified |
| Data_Analysis_11 | Fantasy Football Rankings | Rank, Tier, Player, Team, Position, Bye Week, Strength of Schedule, ECR vs ADP. Sourced from [FantasyPros Expert Consensus Rankings](https://www.fantasypros.com/nfl/rankings/consensus-cheatsheets.php) and Yahoo Sports ADP data |

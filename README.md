#  Excel Data Analysis Practice


This project contains multiple Excel datasets used for practicing **data cleaning, transformation, analysis, and reporting techniques** 
in Excel.

Each Excel file starts with a **raw dataset** and demonstrates various operations performed to convert the data into meaningful 
and usable insights.


The repository includes multiple Excel workbooks covering:

* Raw data handling
* Data cleaning techniques
* Data transformation
* Pivot Tables
* Charts & visualizations
* Basic analytics
* Dashboard-style summaries
* Excel formulas and functions

## 📊 Datasets Used

| File | Dataset | Description |
|------|---------|-------------|
| Data_Analysis_01 | Gym Equipment Sales | Monthly profit by category, supplier, brand |
| Data_Analysis_02 | Car Specifications | Make, model, price, horsepower, fuel economy |
| Data_Analysis_03 | Client Revenue & Profit | Revenue/profit by client and department |
| Data_Analysis_04 | Employee Records (Dirty Data) | Emp ID, department, salary, start date |
| Data_Analysis_05 | Financial Sample | Segment/Country/Product sales, COGS, profit. Microsoft's official [Financial Sample](https://go.microsoft.com/fwlink/?LinkID=521962) dataset, from the [Simon Sez IT webinar](https://www.youtube.com/watch?v=8Ix_VVcihqg) |
| Data_Analysis_06 | US Presidents & Party Data | President, party, VP, salary — cleaning practice |
| Data_Analysis_07 | Customer Purchases | Age, gender, purchase date/amount, location |
| Data_Analysis_08 | 500 Greatest Albums | Year, Album, Artist, Genre, Sales (1955–2011). Based on [Rolling Stone's 500 Greatest Albums](https://www.kaggle.com/datasets/notgibs/500-greatest-albums-of-all-time-rolling-stone) |
| Data_Analysis_09 | Sales Data (Reconstructed) | Month/Store/Country/Category sales — rebuilt practice file |
| Data_Analysis_10 | Stock Price Data (OHLCV) | Date, Ticker, OHLC, Volume — cleaning practice |
| Data_Analysis_11 | Fantasy Football Rankings | Rank, Tier, Player, Team, ECR vs ADP. [FantasyPros ECR](https://www.fantasypros.com/nfl/rankings/consensus-cheatsheets.php) + Yahoo Sports ADP |
| Data_Analysis_12 | Hotel/Travel Booking Records | Date, Company, Person, Room, booking platform — "Fill Down" practice |
